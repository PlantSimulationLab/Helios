# Atmospheric look-up table

`atmosphere_lut.bin` is read by `SolarPosition::calculateSensorAtmosphereSpectra()`; its gas transmittance tables are also used by the spectral solar irradiance model (`calculateGlobalSolarSpectrum()` and related methods). It contains numerical output of the 6S radiative transfer code (6SV1.1, run through the Py6S wrapper), generated by `plugins/solarposition/utilities/generate_atmosphere_lut.py`, which documents its contents and binary format. The provenance string stored in the file records the generation date, the Py6S version, and the 6S release (6SV1.1, as recorded by the generator). No 6S source code is distributed with Helios.

It is validated against direct 6S runs by `plugins/solarposition/utilities/compare_with_6s.py` (sensor atmosphere) and `plugins/solarposition/utilities/compare_spectral_with_6s.py` (spectral solar irradiance). The gas tables were regenerated on their own, with extended absorber ranges, using the generator's `--gas-only-from` option; the provenance string records this.

- Vermote, E. F., Tanré, D., Deuzé, J. L., Herman, M., & Morcrette, J.-J. (1997). Second Simulation of the Satellite Signal in the Solar Spectrum, 6S: an overview. IEEE Transactions on Geoscience and Remote Sensing, 35(3), 675-686. doi:10.1109/36.581987
- Kotchenova, S. Y., Vermote, E. F., Matarrese, R., & Klemm, F. J. (2006). Validation of a vector version of the 6S radiative transfer code for atmospheric correction of satellite data. Part I: Path radiance. Applied Optics, 45(26), 6762-6774. doi:10.1364/AO.45.006762
- Wilson, R. T. (2013). Py6S: A Python interface to the 6S radiative transfer model. Computers & Geosciences, 51, 166-171. doi:10.1016/j.cageo.2012.08.002
