# Thermal infrared atmospheric look-up table

`thermal_atmosphere_lut.bin` is read by `SolarPosition::calculateSensorThermalAtmosphere()` and `SolarPosition::getThermalSkyFlux()`. It contains numerical output of the uvspec radiative transfer tool of libRadtran 2.0.6, with the REPTRAN fine (1 cm⁻¹) molecular absorption parameterization, generated by `plugins/solarposition/utilities/generate_thermal_atmosphere_lut.py`. That script documents the table's contents, the atmospheric profiles and the method. The file uses the same binary format as `../atmosphere_lut/atmosphere_lut.bin` (see `plugins/solarposition/utilities/helios_lut.py`). The provenance string stored in the file records the generation date, the libRadtran version and the settings. No libRadtran source code or REPTRAN data files are distributed with Helios.

Generation environment: libRadtran 2.0.6 from conda-forge (`conda create -n helios-libradtran -c conda-forge rubin-libradtran python=3.12 numpy`), with the REPTRAN thermal fine data files taken from `reptran_2024_all.tar.gz` on the [libRadtran download page](https://www.libradtran.org/doku.php?id=download).

Inputs besides the libRadtran data:
- Atmospheric profiles of Anderson et al. (1986), as distributed with libRadtran (`data/atmmod`).
- CO2 425.62 ppm, CH4 1935.94 ppb and N2O 338.85 ppb: the 2025 global annual means of the NOAA Global Monitoring Laboratory (https://gml.noaa.gov/ccgg/trends/; files `co2_annmean_gl.txt`, `ch4_annmean_gl.txt`, `n2o_annmean_gl.txt`).

Validation (results are summarized in `plugins/solarposition/doc/SolarPosition.dox`, section "Thermal Infrared Atmosphere Between the Scene and a Satellite Sensor"):
- `plugins/solarposition/utilities/compare_thermal_with_uvspec.py`: the table as used by Helios against direct uvspec runs at states between its nodes, and (`--held-out`) the table's profile assumption against an atmosphere outside its climatology.
- `plugins/solarposition/utilities/compare_thermal_with_lblrtm.py`: uvspec with REPTRAN against the line-by-line model LBLRTM 12.17 for the same profiles. LBLRTM is used only as an offline reference; none of its code or output is distributed with Helios.
- `plugins/solarposition/utilities/compare_thermal_with_jms.py`: the table against the generalized atmospheric functions of Jiménez-Muñoz and Sobrino (2003) within 10-12 µm.
