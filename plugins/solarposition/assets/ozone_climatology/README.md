# Total column ozone climatology

`sbuv_total_ozone_climatology.txt` is read by `SolarPosition::getOzoneColumn()`. It holds the monthly zonal-mean total column ozone, in Dobson units, in 36 latitude bands 5 degrees wide, averaged over 2005-2024 from the NASA SBUV Merged Ozone Data Set (MOD), version 8.7. It was generated by `plugins/solarposition/utilities/generate_ozone_climatology.py`, which documents the averaging; band-months with too few years of data (high-latitude winter and all months poleward of 80 degrees) are marked `nan`.

Data source: NASA Goddard Space Flight Center, SBUV Merged Ozone Data Set, https://acd-ext.gsfc.nasa.gov/Data_services/merged/. Data from NASA-led missions that carry no other license are released as Creative Commons Zero (CC0), with a request that the data set be cited (https://www.earthdata.nasa.gov/engage/open-data-services-software-policies/data-use-guidance).

Reference: Frith, S. M., Kramarova, N. A., Stolarski, R. S., McPeters, R. D., Bhartia, P. K., & Labow, G. J. (2014). Recent changes in total column ozone based on the SBUV Version 8.6 Merged Ozone Data Set. Journal of Geophysical Research: Atmospheres, 119, 9735-9751. doi:10.1002/2014JD021889
